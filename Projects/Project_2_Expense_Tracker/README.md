# Expense Tracker

A command-line program for recording positive, whole-number expense amounts during a session.

## Features

- Enter expenses until you type `quit`
- Reject invalid or non-positive amounts
- Display each entered transaction, the transaction count, and the total

## Run

From this folder, run:

```bash
python expense_tracker.py
```

Expenses are kept in memory and are not saved after the program exits.
