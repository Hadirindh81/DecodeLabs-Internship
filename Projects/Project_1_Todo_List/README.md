# To-Do List

A command-line task manager written in Python. Tasks are kept in memory while the program runs.

## Features

- Add non-empty tasks
- List all tasks
- Search tasks by a word or phrase (case-insensitive)
- Remove a task by its number

## Run

From this folder, run:

```bash
python todo_list.py
```

Choose an option from the menu and follow the prompts. Tasks are not saved after exiting the program.
