# DecodeLabs Internship Projects

This repository contains Python projects completed as part of the DecodeLabs internship.

## Projects

| Project | Description |
| --- | --- |
| [To-Do List](Projects/Task01_Muhammad_Abdul_Hadi/README.md) | Add, view, search, and remove tasks in a command-line application. |
| [Expense Tracker](Projects/Task02_Muhammad_Abdul_Hadi/README.md) | Enter expenses and view a transaction list and total. |
| [Random Password Generator](Projects/Task03_Muhammad_Abdul_Hadi/README.md) | Generate a password with lowercase, uppercase, numeric, and special characters. |
| [General Knowledge Quiz](Projects/Task04_Muhammad_Abdul_Hadi/README.md) | Test general knowledge with multiple-choice questions, scoring, and replay support. |

## Requirements

- Python 3

Each project is a standalone command-line program. Open a terminal in its project folder and run the command shown in that project's README.
